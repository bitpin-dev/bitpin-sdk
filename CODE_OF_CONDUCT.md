# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, assume good intent, and keep discussion about the work.

Report unacceptable behaviour privately to the maintainers through a GitHub security advisory or by contacting a maintainer listed in `.github/CODEOWNERS`. Reports are handled confidentially.
